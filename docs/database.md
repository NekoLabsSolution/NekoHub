# Database & Migrations

## Technology

- **Database**: Neon PostgreSQL (serverless)
- **ORM**: Prisma 7 with `@prisma/adapter-neon` (HTTP-based driver)
- **Connection**: Pooled at runtime; direct for migrations
- **Config**: `prisma.config.ts` at repo root

## Schema Location

`prisma/schema.prisma` — single source of truth. Do not edit migration SQL files directly.

## ID Strategy

All IDs are `UUID` generated by `gen_random_uuid()` at the database level — do not generate UUIDs in application code for new records.

## Monetary Values

All amounts stored as **integer cents** (`Int`). Examples:

- `amountCents: 9700` = R$97,00
- `commissionRate: 0.3000` (Decimal 5,4) = 30%

## Key Constraints & Indexes

- `users.email` — unique
- `users.cpf` — unique (nullable)
- `products.slug` — unique, indexed
- `orders.stripePaymentIntentId` — unique, indexed
- `affiliates.(userId, productId)` — composite unique
- `product_access.(buyerId, productId)` — composite unique (one access record per buyer/product)
- `webhooks_log.stripeEventId` — unique (idempotency fence)

## Migrations

### Running migrations (development)

```bash
npx prisma migrate dev --name <migration-name>
```

### Applying to production

```bash
npx prisma migrate deploy
```

### Regenerate Prisma client after schema change

```bash
npx prisma generate
```

### How `prisma.config.ts` works

- Loads env via `@next/env` (`loadEnvConfig`)
- Converts `DATABASE_URL` (pooled) to a direct URL by removing `-pooler.` from hostname and stripping `channel_binding` param
- The direct URL is derived from `DATABASE_URL` by this transformation — no separate variable needed

## Rules

- Never manually edit files in `prisma/migrations/`
- Always run `prisma generate` after schema changes during development
- Migrations in CI/CD use `prisma migrate deploy`

## Known Gaps

- No soft-delete strategy defined (models only have `updatedAt`, no `deletedAt`)
- No audit log table for sensitive operations (e.g., access revocation, payout changes)
- `payoutSchedule` on `Producer` is a free-form string; could be an enum
